📘 Introduction au Codage et Décodage

🎯 Qu'est-ce que le Codage ?

Le codage est le processus de conversion d'informations dans un format spécifique (comme binaire ou hexadécimal) pour les rendre compatibles avec un système informatique. Il permet de préparer les données pour le stockage, la transmission, ou le traitement.

🎯 Qu'est-ce que le Décodage ?

Le décodage est le processus de conversion des données codées dans leur format d'origine pour les rendre compréhensibles. Il permet de récupérer l'information initiale après avoir été transformée pour un usage informatique.

🔷 Conversion de la Base 16 (Hexadécimal)

1️⃣ Base 16 → Base 10 (Décodage)

Règle : Multiplier chaque chiffre par 16 élevé à la puissance de sa position (en commençant à droite avec la position 0), puis additionner.

2️⃣ Base 16 → Base 8 (Décodage)

Règle :
  1. Convertir le nombre hexadécimal en base 2
  2. Regrouper les bits par groupes de 3 (de la droite)
  3. Convertir chaque groupe en équivalent octal

3️⃣ Base 16 → Base 2 (Décodage)

Règle : Remplacer chaque chiffre hexadécimal par son équivalent binaire sur 4 bits.

🔶 Conversion de la Base 10 (Décimal)

1️⃣ Base 10 → Base 16 (Codage)

Règle : Diviser le nombre par 16, prendre le reste à chaque étape. Continuer jusqu'à quotient = 0.

2️⃣ Base 10 → Base 8 (Codage)

Règle : Diviser le nombre par 8, prendre le reste à chaque étape. Continuer jusqu'à quotient = 0.

3️⃣ Base 10 → Base 2 (Codage)

Règle : Diviser le nombre par 2, prendre le reste à chaque étape. Continuer jusqu'à quotient = 0.

🟢 Conversion de la Base 8 (Octal)

1️⃣ Base 8 → Base 16 (Décodage)

Règle :
  1. Convertir en binaire (chaque chiffre octal → 3 bits)
  2. Regrouper les bits par 4 (de la droite)
  3. Convertir chaque groupe en hexadécimal

2️⃣ Base 8 → Base 10 (Décodage)

Règle : Multiplier chaque chiffre par 8 élevé à la puissance de sa position, puis additionner.

3️⃣ Base 8 → Base 2 (Décodage)

Règle : Remplacer chaque chiffre octal par son équivalent binaire sur 3 bits.

⚫ Conversion de la Base 2 (Binaire)

1️⃣ Base 2 → Base 16 (Codage)

Règle :
  1. Regrouper les bits par 4 (de la droite)
  2. Convertir chaque groupe en hexadécimal

2️⃣ Base 2 → Base 10 (Décodage)

Règle : Multiplier chaque chiffre binaire par 2 élevé à la puissance de sa position (en partant de 0 à droite), puis additionner.

3️⃣ Base 2 → Base 8 (Codage)

Règle :
  1. Regrouper les bits par 3 (de la droite)
  2. Convertir chaque groupe en octal
